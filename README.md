# 紅果電視 Samsung 適配層 0.3.21

將既有紅果電視介面與服務適配至 Samsung Tizen 的原始程式、建置工具及測試。本倉庫公開的是 **Samsung 適配層**，沒有附上完整上游應用、影片、可直接安裝的 WGT 或 Samsung 簽章憑證。

目前只在 Samsung QA65Q70TAWXZW（Q70T／Tizen 5.5）測試。其他 Samsung 型號與 LG 電視尚未由本專案驗證。

## 提供的功能

- Samsung 原生 AVPlay 播放與解碼資源設定。
- 電視本機服務啟動、舊版 Node 相容處理及本機請求適配；正常觀看不需要電腦提供內容服務。
- 保留 Range 邊載入邊播放，完整下載備援快取上限 256 MiB，交接保護 8 秒。
- 遙控器操作、畫面更新與預載調整，以及對應回歸測試。

## 本機建置

需要 Python 3.9 以上、Node.js 20 以上／npm，以及打包、安裝時使用的 PowerShell 7。依賴的上游 IPK 版本與校驗值由建置設定固定：介面來自 0.2.117-test.25，服務來自 0.2.147-test.26。下載工具會取得這些檔案供本機建置，不會將它們加入本倉庫。

```powershell
python scripts/fetch-upstream.py
npm run build
npm test
pwsh ./scripts/Package.ps1
```

0.3.21 使用與本機電視版本相同的 0.2.147 服務核心及 Samsung 播放適配，不再載入或接受獨立的 `fallback-model.js`。建置所需檔案均由上述固定上游輸入與本倉庫適配程式產生。

## 安裝到電視

電視需啟用 Samsung Developer Mode，電腦與電視需可互相連線。自行準備 Apps2Samsung 安裝工具，以及可供該電視使用的 Samsung 開發者簽章設定。將下列範例換成自己的電視位址及工具路徑：

```powershell
pwsh ./scripts/Install.ps1 -TvIP 192.168.1.50 -InstallerPath C:/tools/apps2samsung-cli.exe -ProfileDir C:/private/Apps2Samsung-data
```

憑證與私鑰留在自己的電腦。不要提交簽章設定、帳號資料或已簽章安裝包。更新既有安裝時，保留原簽章設定及應用識別，避免先解除安裝而丟失觀看紀錄。

## 0.3.21 更新

2026-11-04 的舊版電視服務反覆回報 `VIDEO_MODEL_EMPTY`；當時影片快取為空，失敗發生於取得播放地址階段。0.3.21 將服務核心由 0.2.127 更新至 0.2.147，採用上游修正後的簽章／gzip 請求、官方備用地址及有界匿名播放身分恢復，保留 Range 播放與快取上限。確認空回應後的身分恢復冷卻縮為 2 秒，讓快速切集能重新取得片源；並行請求仍共用一次註冊，取消與重試限制繼續生效。

同一失敗分集在電腦以全新播放身分測試，新核心第一次請求成功取得片源。電視更新服務後，已測到一集完整播放 81.525 秒，再自動接下一集；首個播放進度間隔 5.092 秒。追加冷卻修正並重新安裝後，四次連續頻道鍵事件均確認正播放進度與無播放器錯誤，App 關閉重開並移除電腦偵錯連線後仍持續播放。完整播完觀察與最終快速切集觀察分屬兩個修正階段，不代表最終版已重新測過所有整集、長時間連播或整台電視冷開機。

## 驗證範圍與歷史紀錄

下列為先前本機 0.3.20 在上述 Q70T 上直接讀取的播放紀錄，僅作歷史參考，不是本輪 0.3.21 的重新驗收：

- 《nova：新星》第四集完整播放 135.276 秒，接第五集的首次播放進度間隔為 1.651 秒。
- 另一段影片完整播放 179.954 秒，接續 178.863 秒影片的首次進度間隔為 2.045 秒。
- 10 次 ChannelUp／ChannelDown 事件切換後均取得 PLAYING 狀態且錯誤欄為空；9 次取樣已有正播放進度，1 次仍為 0，不能將該次算作已確認持續播放。

按鍵測試由電視瀏覽引擎注入事件；沒有相機或麥克風驗收。整台電視斷電冷開機仍待驗證。這些結果不保證所有片源、網路及機型都能以相同速度播放。
